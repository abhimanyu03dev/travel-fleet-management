# Travel Fleet Management System

A full-stack Travel Fleet Management System built using Java, Spring Boot, Microservices, MySQL and React.

## Tech Stack

### Backend
- Java 21
- Spring Boot
- Spring Cloud
- Spring Security
- JWT
- MySQL
- REST APIs
- OpenFeign

### Frontend
- React
- React Router
- Axios

### Infrastructure
- Docker
- GitHub Actions

## Microservices

- Auth Service
- Customer Service
- Vehicle Service
- Driver Service
- Booking Service
- Trip Service
- Fuel Service
- Expense Service
- Maintenance Service
